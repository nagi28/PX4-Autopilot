# PX4 自律制御開発ガイド（日本語）

PX4-Autopilot のソースコードを読み解き、**自律制御するドローンを作る**ための解説書です。
公式ドキュメント（`docs/en/`）が「機能の使い方」を説明するのに対し、本書は
**「どのファイルのどの関数が、どの uORB トピックを介して何をしているか」** を軸に構成しています。

- 対象機体: **マルチコプター中心**（固定翼・VTOL・Rover は対応関係の概観のみ）
- 方針: 数式よりも **仕組みとデータの流れ**、そして **どこを触ると何が変わるか**
- すべての説明は **実在するファイルパス** に紐づけています。そのままエディタで開いてください

> [!NOTE]
> 本書は特定時点のソースツリーを読んで書かれています。行番号は目安です。
> 関数名・クラス名で検索すれば、多少コードが動いても追随できます。

## 目的別の読み方

### 「まず全体像を掴みたい」

01 → 02 → 04 → 05 の順。
04 章の [制御チェーン全体図](04_control_cascade.md#制御チェーン全体図) が本書で一番重要な図です。

### 「すぐに Offboard で飛ばしたい」

02（uORB の基礎）→ 07（Offboard）→ 11（SITL）。
04 章の「[どの階層に注入するか](04_control_cascade.md#どの階層に注入できるか)」を併読すると、
位置・速度・姿勢・角速度のどれを送るべきか判断できます。

### 「PX4 のコードを改造したい／独自制御則を入れたい」

01 → 02 → 04 → 08。
既存の制御段を差し替えるなら 04 章、新しいモードを足すなら 06 章と 08 章。

### 「ROS 2 で本格的に自律機を組みたい」

02 → 04 → 09 → 10。
Offboard より先に 09 章（外部モード）を読むことを勧めます。
Offboard は「モードを乗っ取る」方式ですが、外部モードは「モードとして登録される」方式で、
アーミングチェックやフェイルセーフと正しく統合されます。

### 「トラブルシュートしたい」

02 章の[調査コマンド](02_uorb_runtime.md#27-実機と-sitl-で使う調査コマンド)と
05 章の[フェイルセーフ](05_modes_safety.md#55-フェイルセーフの仕組み)から。
`listener` と `uorb top` でトピックの流れを追うのが基本です。

## 本書の 3 つのキーコンセプト

読み進める前に、これだけ頭に入れておくと理解が速くなります。

### 1. すべては uORB トピックで繋がっている

PX4 のモジュールは互いを直接呼びません。**uORB という pub/sub メッセージバス**にだけ依存します。
「制御を差し込む」とは「あるトピックの publisher になる」ことと同義です。

```
モジュールA ──publish──> [uORB トピック] ──subscribe──> モジュールB
```

→ 詳細: [02 章](02_uorb_runtime.md)

### 2. 制御は 4 段のカスケード

```
trajectory_setpoint (位置/速度/加速度)
    ↓ mc_pos_control
vehicle_attitude_setpoint (姿勢クォータニオン + 推力)
    ↓ mc_att_control
vehicle_rates_setpoint (角速度)
    ↓ mc_rate_control
vehicle_thrust_setpoint / vehicle_torque_setpoint
    ↓ control_allocator
actuator_motors (各モータへの指令)
```

**どの段のトピックにも外部から割り込める**のが PX4 の設計です。
上流に入るほど PX4 の安全機構の恩恵を受け、下流に入るほど自由度が上がります。

→ 詳細: [04 章](04_control_cascade.md)

### 3. `NaN` は「その軸を制御しない」という意味

PX4 の設定値メッセージでは、**フィールドに `NaN` を入れると「その自由度は制御対象外」**を意味します。
0 を入れるのとはまったく違います（0 は「0 にせよ」という指令）。

例: `TrajectorySetpoint` で `position = {NaN, NaN, -5.0}`, `velocity = {2.0, 0.0, NaN}` と送ると、
「水平は速度 2 m/s 北向き、垂直は高度 5 m を保持」という意味になります。

この判定は `PositionControl::_inputValid()`
（`src/modules/mc_pos_control/PositionControl/PositionControl.cpp`）で行われています。

→ 詳細: [04 章](04_control_cascade.md#nan-イディオム)

## 安全に関する注意

自律制御の開発は、**必ず SITL → 屋内テストベンチ → 屋外実機** の順で進めてください。

- Offboard 制御と外部モードは、外部プログラムがバグると機体が制御不能になります
- **必ず手動操作に戻せる手段（RC 送信機のモードスイッチ、キルスイッチ）を用意**してください
- PX4 のフェイルセーフを無効化するパラメータ変更（`NAV_DLL_ACT 0` など）は
  SITL 専用と考えてください。実機では外さないこと

→ 各ルートの失敗時挙動: [10 章](10_route_comparison.md#103-失敗時の挙動比較)
